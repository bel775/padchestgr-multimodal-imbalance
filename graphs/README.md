# Training outputs and evaluation tables

This directory contains plots and CSV reports generated by `main.py`. Files are
created or updated only after the relevant training or evaluation step finishes.

## Loss curves

Neural-network experiments create one PNG containing the training and validation
loss per epoch:

```text
loss_curve_<configuration>_Labels<label_count>.png
```

Five-fold cross-validation creates one plot per fold:

```text
loss_curve_<configuration>_Labels25_Fold1.png
...
loss_curve_<configuration>_Labels25_Fold5.png
```

The configuration portion can include the image model, text model, cleaning
stage, frozen backbones, and enabled imbalance strategies (`WRS`, `CW`,
`DataAug`, or `OS`). Including `LabelsN` prevents experiments with different
label counts from overwriting one another.

TF-IDF + Linear SVM does not train by epoch, so it does not create a loss plot.

## Consolidated non-cross-validation results

`experiment_results.csv` records completed experiments that meet both of these
conditions:

- cross-validation is disabled;
- final lexical cleaning is selected with `--textCleaning 2`.

Each row contains the experiment configuration (models, balancing options,
freezing options, label count, cleaning stage, and seed) followed by Macro-F1,
precision, recall, multilabel subset accuracy, ROC-AUC, and Macro-AUPRC.
Running the same configuration again replaces its previous row; changing an
identity field such as the seed or label count creates a separate row.

## Text-leakage comparison

`text_leakage_comparison.csv` compares non-cross-validation text-only runs at
the three cleaning stages:

- `Before_Cleaning` (`--textCleaning 0`)
- `After_Label_Cleaning` (`--textCleaning 1`)
- `After_Lexical_Filter` (`--textCleaning 2`)

It includes F1, precision, recall, accuracy, ROC-AUC, and Macro-AUPRC. The same
text model, cleaning stage, and label count combination is updated rather than
duplicated.

## Five-fold cross-validation results

Cross-validation is kept separate from `experiment_results.csv`. Every
cross-validation experiment creates three CSV files with a shared prefix:

```text
cross_validation_<configuration>_Labels25_folds.csv
cross_validation_<configuration>_Labels25_per_class_folds.csv
cross_validation_<configuration>_Labels25_per_class_summary.csv
```

Their contents are:

| Suffix | Contents |
| --- | --- |
| `_folds.csv` | Macro-F1 and Macro-AUPRC for each fold |
| `_per_class_folds.csv` | F1 and AUPRC for every class in every fold |
| `_per_class_summary.csv` | Per-class mean and sample standard deviation across folds |

The final row of the per-class summary is `Overall Average`. It averages all
class rows for `F1_Mean`, `F1_Std`, `AUPRC_Mean`, and `AUPRC_Std`.

## Metric notes

- Macro-F1, precision, and recall give every label equal weight.
- Accuracy is exact-match (subset) accuracy: every predicted label for a sample
  must match its target.
- ROC-AUC uses prediction probabilities or decision scores and is macro-averaged.
- Macro-AUPRC is the mean per-class area under the precision-recall curve.
- A metric can be `NaN` when it is mathematically undefined, for example when a
  test fold contains no positive examples for a class.

These files are generated outputs. Keep this `README.md` in version control;
large or frequently regenerated result files can be archived separately if
required by the project workflow.
